# Project Statement

## Problem Statement
Solving a Sudoku puzzle manually can require checking many possible
number combinations. The project provides a Java-based 4x4 Sudoku
solver that accepts a partially completed puzzle and automatically
finds a valid solution.

## Scope
The project is limited to standard 4x4 Sudoku puzzles. The puzzle
contains four rows and four columns and is divided into four 2x2 boxes.
The values used are 1, 2, 3, and 4, while 0 represents an empty cell.

## Target Users
- Students learning Java programming
- Beginners learning recursion and backtracking
- Users who want to solve small Sudoku puzzles

## High-Level Features
1. Sudoku input
2. Puzzle validation
3. Automatic solving
4. Error handling
5. Console-based result display

## Java Concepts Demonstrated
- Classes and objects
- Constructors
- Encapsulation
- Arrays
- Methods
- static methods
- Exception handling
- Custom exception
- Recursion
- Backtracking
